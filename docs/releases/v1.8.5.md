# AIQuotaMonitor v1.8.5

2026-11-20

## 更新

- **Kimi 登录**。使用会员订阅页的卡片现在直接打开 Kimi 首页来登录，避开未登录时从订阅页跳转后按钮无响应的问题。登录后关闭窗口即可刷新订阅额度。
- **标题栏时钟**。右上角显示本地时间 `HH:mm`，每分钟更新。
- **单卡与全体刷新**。卡片上的刷新按钮只刷新该服务，标题下方显示服务名。标题栏的全体刷新会处理所有已启用且未暂停的服务，并显示「正在刷新全部」。定时刷新在各服务到期时执行，并显示当前服务名。

## What's changed

- **Kimi sign-in.** Cards configured with Kimi's subscription page now open the Kimi homepage for sign-in, where the button responds. Close the window after signing in to refresh the subscription quota.
- **Title-bar clock.** The upper-right clock shows local time in `HH:mm` and updates each minute.
- **Single-card and full refresh.** A card's refresh button now updates only that service and shows its name below the title. Refreshing all updates every enabled, unpaused service and shows “Refreshing All”. Scheduled refreshes name the service as it is refreshed.

## 升级 / Upgrade

从托盘退出旧版本，替换 `AIQuotaMonitor.exe`，保留同目录的 `config.json`。

Exit the old app from the tray, replace `AIQuotaMonitor.exe`, and keep `config.json` beside it.
