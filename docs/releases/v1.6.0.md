# AIQuotaMonitor v1.6.0

发布日期：2026-09-05

## 重点更新

- **同一供应商多账号**：服务在设置里勾选「独立会话（同站点多账号）」后，使用该服务独立的 WebView2 profile 与独立 DPAPI 加密 Cookie 存储（按服务 Id 隔离），同一供应商的多个账号可并排监控、互不串号。登录窗口与抓取始终落在同一会话上；未勾选的服务维持共享 profile，同一域名仍只需登录一次。
- **赠送用量重置**（Codex / 智谱 GLM）：卡片新增一行显示可用重置次数与最早到期时间，悬停逐条列出适用范围与有效期；最早到期进入 24 小时变黄提醒，已过期次数自动隐藏。
  - Codex「Usage limit resets」：直接识别每条 Full/Partial reset 及其到期时间（可多条，各自不同）。
  - 智谱「用量重置额度」：页面直显的次数直接读取；每条的到期时间在「重置管理」弹层里，抓取时自动点开读取再关闭，全程 best-effort，失败不影响配额主结果。

## 解析与可靠性

- 新增英文月名日期的显式解析（`Oct 4, 9:57 AM`、`October 4, 2026, 9:57 AM` 等）：BCL `DateTime.TryParse` 对无年份英文月名+时间的解析结果不可靠，不再依赖。
- 退出时保存所有已初始化会话（共享 + 各独立会话）的 Cookie，独立会话的登录态同样跨进程存活。

## 验证

- 回归测试扩展到 42 项：Codex 双条目解析（含 AM/PM 与年份推断）、智谱页面直显与弹层到期时间合并、次数用尽不显示、损坏 payload 容错、独立会话开关的配置序列化。
- `dotnet build` / `dotnet publish`（Release, win-x64 自包含单文件）通过。

## 升级方式

1. 从托盘菜单退出旧版本。
2. 下载并替换 `AIQuotaMonitor.exe`。
3. 保留 exe 同目录的 `config.json`。

登录态、最后成功数据与历史记录位于 `%LOCALAPPDATA%\AIQuotaMonitor\`，无需迁移。多账号用法：为第二个账号的服务勾选「独立会话」，然后点该卡片的「去登录」登录一次即可。供应商服务端主动过期或撤销的会话仍需重新登录。
