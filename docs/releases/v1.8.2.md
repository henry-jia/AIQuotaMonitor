# AIQuotaMonitor v1.8.2

发布日期 / Release date: 2026-11-11

## 可配置 Credits 上限 / Configurable Credits limit

- **默认上限 62500**：每个服务新增 `creditsLimit` 配置，旧配置无需手工迁移，首次使用时自动采用默认值。
- **服务级设置**：在「设置 → 服务 → 服务配置」的“订阅信息网址”下方新增 **Credits 上限**。不同 Codex 账号可设置不同上限。
- **按需显示**：该字段只对 ChatGPT/Codex Usage 页面显示，支持新版 `/settings/usage` 与旧版 `/#settings/Usage`；其他供应商不显示。
- **保存立即生效**：已用量 = 上限 − 当前余额（最低 0），余额条显示当前余额占设置上限的比例；无需等待下一次网页抓取。
- **超额语义明确**：余额超过上限时条形填满，消耗不会显示负数。该上限是用户配置的计算基准，不声称是官方固定总额度。
- 移除 1.8.0 引入的“本机最高余额”基准，余额快照与扫描失败回退行为保留。

Each service now has a `creditsLimit` setting defaulting to **62500**, with no manual migration for existing configurations. The numeric field is below Subscription URL in **Settings → Services → Service** and appears only for ChatGPT/Codex Usage URLs, including the legacy hash route. Different Codex accounts can use different limits. Saving immediately recalculates consumption and the bar without waiting for another scrape: used = limit − balance (minimum 0). Balances above the limit fill the bar and never produce negative consumption. The configured limit is a local calculation reference, not an official provider total. The previous local highest-balance reference has been removed; balance snapshots and failure fallback remain intact.

## 升级 / Upgrade

1. 从托盘退出旧版本 / Exit the old app from the tray.
2. 替换 `AIQuotaMonitor.exe`，保留同目录的 `config.json` / Replace the executable and keep `config.json`.
3. 启动 1.8.2。已有 Codex 服务自动使用上限 62500；需要调整时打开「设置 → 服务」，修改 **Credits 上限** 并保存 / Start 1.8.2. Existing Codex services use a limit of 62500 automatically. To change it, open **Settings → Services**, edit **Credits limit**, and save.
