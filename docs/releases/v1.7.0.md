# AIQuotaMonitor v1.7.0

发布日期：2026-09-06

## 新增

- **任务栏占位（默认开启）**：小部件可见时在任务栏出现图标——被其他窗口挡住后，点任务栏即可一键唤回，不必常开「置顶」占用屏幕。「隐藏窗口」收进托盘后不占任务栏。可在「设置 → 全局设置 → 在任务栏显示窗口」关闭；旧配置升级后默认开启。
- **托盘单击唤起**：单击托盘图标一律显示并置前，非置顶窗口也能越过当前前台窗口。替代旧版的双击纯切换——旧版在窗口被挡住时双击会先把它**隐藏**（与意图相反），且非置顶窗口显示后不会被拉到最前。隐藏窗口改用标题栏 ✕、小部件右键菜单，或托盘菜单的「显示 / 隐藏窗口」（保持字面切换）。
- **标题栏显示版本号**：小部件左上角标题旁以灰字显示当前版本（如 `v1.7.0`），无需再从文件属性查看。
- 主窗口与任务栏图标统一使用应用图标（app.ico）。

## 验证

- 回归测试 42/42 通过。
- 实测：任务栏占位显示、点击唤起、设置开关即时生效；托盘单击对「被挡住」与「已隐藏」窗口均置前；隐藏后任务栏占位随之消失；设置关闭后不占任务栏。

## 升级方式

1. 从托盘菜单退出旧版本。
2. 下载并替换 `AIQuotaMonitor.exe`。
3. 保留 exe 同目录的 `config.json`（无必填新字段；`showInTaskbar` 缺省按开启处理）。

> 习惯旧版「托盘双击显示/隐藏」的用户请注意：现在是单击唤起、永不隐藏；隐藏走标题栏按钮或菜单。
