# AIQuotaMonitor v1.8.1

发布日期 / Release date: 2026-11-11

## 修复旧 Codex 地址不显示 Credits / Fix missing Credits on legacy Codex URLs

- **问题**：1.8.0 的 Credits 扫描仅对 `/settings/usage` 与 `/codex/settings/usage` 启用。已有服务若使用旧地址 `https://chatgpt.com/#settings/Usage`，周用量和赠送重置正常，但 Credits 扫描会被整个跳过。
- **修复**：旧 hash 地址现在与新地址一样启用 Credits 扫描；支持大小写与查询参数变体，无需修改已有配置。
- **同步恢复**：未填写自定义订阅网址的旧 hash 服务也会自动读取 Billing 页面；显式自定义网址保持优先。
- **安全边界不变**：仅匹配精确的 `chatgpt.com` 主机与 Usage 页面，不匹配相似域名、Billing 或其他路径。
- 保留 1.8.0 的余额、累计消耗、自动充值、最高余额持久化及失败快照行为。

v1.8.0 enabled Credits only for `/settings/usage` and `/codex/settings/usage`, so existing services using `https://chatgpt.com/#settings/Usage` silently skipped the scan while weekly quota and bonus resets continued working. This hotfix enables Credits for the legacy hash route, including case and query variants, with no configuration migration. Automatic Billing detection receives the same compatibility fix; explicit subscription URLs still win. Matching remains restricted to the exact ChatGPT host and Usage pages. All v1.8.0 Credits behavior is preserved.

- ChatGPT Billing / Usage DOM checks: **23/23 PASS**.
- Navigation recovery checks: **9/9 PASS**.
- Release build is self-contained Windows x64, single-file, with assembly/file version **1.8.1.0**.

## 升级 / Upgrade

1. 从托盘退出旧版本 / Exit the old app from the tray.
2. 替换 `AIQuotaMonitor.exe`，保留同目录的 `config.json` / Replace the executable and keep `config.json`.
3. 启动 1.8.1 并刷新 Codex 卡片。旧 `/#settings/Usage` 地址无需修改，账号、独立会话与历史无需迁移 / Start 1.8.1 and refresh the Codex cards. Existing `/#settings/Usage` URLs, accounts, isolated sessions, and history need no migration.
