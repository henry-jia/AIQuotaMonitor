# AIQuotaMonitor v1.7.5

发布日期 / Release date: 2026-10-05

## 修复 / Fixes

- **已登录仍显示 session expired**：登录窗口与背景抓取网页共享对应账号的 profile，但 `/#settings/Usage` 等 hash 路由可能沿用背景页旧文件及内存中的过期状态。相同文档或 hash 路由再次导航时，现在先离开旧文件再载入目标页面，重新读取当前会话与配额。
- **旧导航事件误放行**：按 NavigationId 对应本次导航，忽略旧导航被取消时的完成事件。
- **取消后仍启动导航**：在导航入口及真正开始载入前检查取消状态。
- 保留卡片上的主动 Sign in 入口与独立账号 profile；真正登出时继续显示读取失败。

The authenticated login window and background scraper shared the correct account profile, but repeated/hash-route navigation could retain the background SPA's old document and expired-session state. Scraping now loads a fresh document before reading the current session and quota. Completion events are matched by NavigationId, and canceled work cannot start another page load. Existing sign-in controls and isolated account profiles are preserved; genuine logout remains a failure.

## 验证 / Validation

- Regression checks: **84/84 PASS**, using a fresh temporary directory.
- Real WebView2 navigation checks: **9/9 PASS**. The original fixture failed three recovery checks before the fix: same-URL quota recovery, new-document creation and hash-route quota refresh.
- Navigation coverage includes login-window storage updates, stale background state, current quota extraction, hash-route changes, isolated profiles, genuine logout and pre-canceled navigation.
- Existing ChatGPT Billing / Usage page checks: **17/17 PASS**.
- Two independent reviewers reproduced the final nine navigation checks and approved the fix.
- The navigation smoke test runs against the published executable in GitHub CI before the release step.
- Tests use local equivalent pages and temporary browser profiles; real account cookies and sessions are untouched. Live-account verification has not been performed.

## 升级 / Upgrade

1. 从托盘退出旧版本 / Exit the old app from the tray.
2. 替换 `AIQuotaMonitor.exe`，保留同目录的 `config.json` / Replace the executable and keep `config.json`.
3. 启动 1.7.5 并刷新卡片。已有账号、独立会话与历史无需迁移 / Start 1.7.5 and refresh; existing accounts, isolated sessions and history need no migration.
4. 若会话确实已过期，使用卡片标题栏的人形 Sign in 按钮登录，完成后关闭登录窗口 / If the session has genuinely expired, use the card header's Sign in button, then close the login window when done.
