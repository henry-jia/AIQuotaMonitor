# AIQuotaMonitor v1.7.2

发布日期：2026-10-04

## 修复

- **ChatGPT 订阅到期日与续订状态**：支持新版 Billing 页「You'll continue to have access to ChatGPT Pro 200 until Oct 19, 2026」等文案，并识别「Your plan is canceled and won't renew」。自动续订状态先出现时，继续等待到期日，避免把不完整结果缓存六小时。
- **自动读取 ChatGPT Billing**：ChatGPT 用量服务未填写订阅信息网址时，自动使用同一账号会话访问 Billing 页；已有自定义网址保持优先，订阅信息沿用六小时缓存。
- **赠送 Reset 信息漏显示**：支持「Expires October 5 / October 23 / October 30」等仅日期格式，同时兼容旧版 AM/PM 时间与 24 小时时间。扫描按每条 Full / Partial reset 分开读取，缺失日期不会串用下一条的有效期。
- **异步加载的 Reset 列表**：等待可用次数与列表加载，避免用量百分比先出现、Reset 后出现时漏抓。
- **仅日期有效期的显示**：保留页面原文，不显示虚构的具体时间；到期日当天仍保留页面列出的可用次数。

## 验证

- 常规回归测试：46/46 通过。
- 隔离 WebView2 DOM 测试：17/17 通过，覆盖两组截图中的 Billing / Usage 文案、旧版时间格式、延迟及逐条加载、跨行日期隔离、零次 Reset、智谱既有格式和不相关日期。
- Windows x64 自包含单文件发布构建通过。
- 测试使用截图等价页面与临时浏览器 profile；未访问真实账号进行在线复核。

## 升级方式

1. 从托盘菜单退出旧版本。
2. 下载并替换 `AIQuotaMonitor.exe`，保留同目录的 `config.json`。
3. ChatGPT / Codex 标准用量页服务会自动读取 Billing，无需新增配置；已有「订阅信息网址」若填错，请改为 `https://chatgpt.com/settings/billing` 或留空。
4. 启动新版并刷新；原有登录态和历史数据无需迁移。
