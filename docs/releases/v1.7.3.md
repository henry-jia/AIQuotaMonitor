# AIQuotaMonitor v1.7.3

发布日期 / Release date: 2026-10-05

## 主动登录 / Sign in at any time

- 每张卡片标题栏新增常驻人形「去登录 / Sign in」按钮，即使自动检测未识别到已登出，也能主动打开登录窗口。
- 正常、加载中、抓取失败、显示旧数据、暂停及刷新忙碌时均可使用。
- 沿用该服务的浏览器会话；独立账号仍使用自己的 profile。关闭窗口后保存会话并重新抓取，暂停的服务恢复后再抓取。
- 提示及辅助功能名称支持中文和英文。

Every card now has a permanent **Sign in** person button in its header. It works even when automatic sign-out detection misses a logout, including loading, normal quota display, errors, stale data, paused and busy states. The existing per-service browser session is reused, preserving isolated account profiles. Close the browser when done to save the session and refresh; paused services refresh after resuming. Tooltips and accessible names support Chinese and English.

## 验证 / Validation

- 83/83 regression checks passed, including 37 card login checks, using a fresh isolated temporary directory.
- English horizontal and Chinese vertical layouts inspected.
- Independent code review passed.
- Live-account sign-in was not tested; authentication and cookie persistence behavior are unchanged.
- The default local temporary directory has a pre-existing cookie fixture replacement failure. Its files were preserved; all persistence assertions passed with the fresh temporary directory.

## 升级 / Upgrade

1. 从托盘退出旧版 / Exit the old app from the tray.
2. 替换 `AIQuotaMonitor.exe`，保留 `config.json` / Replace the executable and keep `config.json`.
3. 启动新版；登录状态、独立会话和历史无需迁移 / Start the new version; sign-in state, isolated sessions and history need no migration.
4. 需要重新登录时，点击卡片标题栏的人形按钮 / Click the card header's person button whenever you need to sign in again.
