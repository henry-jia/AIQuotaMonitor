# AIQuotaMonitor v1.8.4

发布日期 / Release date: 2026-11-13

## 完整 Credit 日用量历史与重复计数修复 / Complete Credit history and duplication fix

- **完整分页采集**：自动遍历 ChatGPT Usage 页 Credit usage history 的全部分页，不再只读取当前显示的 10 条；同一天多笔流水按日正确合计。
- **重复容器去重**：页面通过多个嵌套 DOM 元素暴露同一历史容器时只解析一次，不再把同一流水保存为三份。真实的同日期、同金额、同来源事件仍分别保留。
- **旧数据自动修复**：完整翻页成功后，以权威快照替换对应服务的本地历史，自动清除旧版已保存的三倍重复记录；翻页中断时仅增量合并，不用不完整数据覆盖旧历史。
- **记录起点与近 7 天摘要**：Credit 卡片显示已知记录的最早日期；悬停列出近 7 个自然日内有消耗的每日合计，零用量日期不显示。
- **独立按天图表**：点击 Credit 条打开每日绿色柱状图，默认展示近 30 个自然日，可调整起止日期；打开窗口时触发一次服务刷新。
- **隐私与开关**：数据仅保存在本机 `%LOCALAPPDATA%\AIQuotaMonitor\credit-history.json`，沿用现有「记录用量历史」开关；关闭后不再记录，已有数据保留。

Credit usage history is now collected across every page rather than only the ten currently visible events. Repeated DOM captures of the same container are parsed once, while legitimate identical events remain distinct. After a complete crawl, the service's local snapshot is replaced so triplicated entries saved by the previous version are repaired automatically; interrupted crawls only merge new entries and never overwrite history with a partial snapshot. The card shows the earliest known record date and a seven-day non-zero daily summary. Clicking the Credits row opens a green daily bar chart with a default 30-calendar-day range and adjustable dates. History remains local and follows the existing Record usage history setting.

## 升级 / Upgrade

1. 从托盘退出旧版本 / Exit the old app from the tray.
2. 替换 `AIQuotaMonitor.exe`，保留同目录的 `config.json` / Replace the executable and keep `config.json`.
3. 启动 1.8.4，分别刷新各 Codex 服务。首次完整翻页后会自动修复旧历史，无需删除 `credit-history.json` / Start 1.8.4 and refresh each Codex service. The first complete crawl repairs legacy history automatically; do not delete `credit-history.json`.
4. 点击 Credit 条可触发刷新并查看按天图表 / Click the Credits row to trigger a refresh and open the daily chart.
