# AIQuotaMonitor v1.5.0

发布日期：2026-08-25

## 重点更新

- 登录态保存从「成功抓取后」扩展到每次抓取结果、登录窗口关闭和正常退出。Cookie 使用当前 Windows 用户的 DPAPI 加密，并以原子替换方式写入。
- 修复 Cookie UTC 到期时间与本地时间比较错误，避免仍有效的认证信息被客户端误判为过期。
- 适配火山 Coding Plan 新版页面，识别「当前会话 / 近 1 周 / 近 1 月」及 `后刷新`、紧凑 `时` 格式。
- 0% 且尚未开始计时的 5 小时窗口显示首次调用后开始计时；已有真实重置倒计时不受影响。

## 桌面与可靠性

- 降低 Acrylic tint 遮罩并增加克制的顶部反光，让 Windows 11 毛玻璃更容易透出背景，同时保持文字对比度。
- 标题栏新增置顶图钉，图标、主题色、右键菜单和托盘状态保持同步。
- 退出时停止刷新、取消进行中的抓取，并在有界等待内完成最后一次会话保存，避免程序挂住或 WebView2 状态未落盘。
- 月度配额的时间基准可结合订阅到期时间判断，减少把月度窗口误当短窗口的情况。

## 验证

- Release 回归测试覆盖重置／刷新解析、5 小时空闲提示、Cookie 到期边界、DPAPI 原子保存与退出超时。
- 隔离 WebView2 profile 的会话持久化 smoke 验证 session cookie 保存与恢复，不读取真实账号 Cookie。
- 等价 Volcengine DOM smoke 使用生产抓取脚本提取当前会话、近 1 周和近 1 月状态。
- 独立代码审查与认证／解析专项验证均通过。

## 升级方式

1. 从托盘菜单退出旧版本。
2. 下载并替换 `AIQuotaMonitor.exe`。
3. 保留 exe 同目录的 `config.json`。

登录态、最后成功数据与历史记录位于 `%LOCALAPPDATA%\AIQuotaMonitor\`，无需迁移。供应商服务端主动过期或撤销的会话仍需重新登录。
