# AIQuotaMonitor v1.7.1

发布日期：2026-09-22

## 修复

- **小部件毛玻璃启动全黑、越用越黑**：之前局部重绘（卡片刷新、按钮悬停、滚轮缩放）会把对应区域渲染成不透明黑块，直到整窗变黑，要拖到另一块屏幕才能恢复。根因是 WPF 渲染目标默认用不透明黑清屏，DWM 材质只能在透明像素处透出；现在清屏色设为透明，并在首帧渲染后重应用一次材质，启动即透明、局部更新不再变黑。
- **去掉 Acrylic 的"白膜"感**：小部件背景从系统 Acrylic 材质（自带一层调不掉的亮度混合，且窗口失焦时退化成灰白实底）换为 ACCENT 亚克力接口——纯模糊 + 自定义 tint，画面更干净，失焦后模糊依旧；压暗仍由设置里的背景色（tint）控制。接口不可用时自动回退原系统材质。

## 验证

- 回归测试全部通过。
- 实测：启动即透明；卡片自动刷新、按钮悬停、滚轮缩放、跨屏拖动均不再出现黑块；失焦后模糊保持，无灰白蒙层。

## 升级方式

1. 从托盘菜单退出旧版本。
2. 下载并替换 `AIQuotaMonitor.exe`。
3. 保留 exe 同目录的 `config.json`（无必填新字段）。
