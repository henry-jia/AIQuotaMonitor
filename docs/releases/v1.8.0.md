# AIQuotaMonitor v1.8.0

发布日期 / Release date: 2026-11-11

## Codex Credits 监控 / Codex Credits monitoring

- **每周用量下新增 Credits 监控条**：显示当前余额、累计已用数量和自动充值状态。套餐周配额达到 100% 后，仍可继续跟踪 Credit 消耗。
- **余额变化有明确基准**：ChatGPT 没有提供 Credits 固定总额度，因此条形表示相对本机最高余额的剩余比例，而不是虚构的官方百分比。充值或赠送导致余额升高时，基准自动上调。
- **重启后延续统计**：最高余额随上次成功结果保存在本机 `lastgood.json`，现有百分比用量历史保持不变。
- **无需新增配置或导航**：标准 ChatGPT / Codex Usage 页在原有抓取中一并读取 Credits，支持延迟渲染、开放 Shadow DOM 和中英文页面。
- **避免误读与失败扩散**：Credit usage history 中的单笔扣费不会被当成余额；单次扫描失败保留上次快照，不影响其他配额，整张卡片回退旧数据时也包含 Credits。
- 找不到周配额标签时，Credits 放到卡片末尾；余额为零时使用告警色。悬停可查看基准说明和余额更新时间。

A new Credits row sits below weekly usage and shows the current balance, locally observed consumption, and automatic-reload state. ChatGPT exposes no fixed Credits total, so the bar represents the remaining share of the highest balance observed locally rather than an invented official percentage. Reloads and grants raise that reference automatically; it persists in `lastgood.json` across restarts. Standard Usage pages need no extra configuration or navigation. Delayed rendering, open shadow roots, and Chinese/English text are covered. Credit-history entries are excluded, and scan failures retain the previous snapshot without affecting other quota results.

## 升级 / Upgrade

1. 从托盘退出旧版本 / Exit the old app from the tray.
2. 替换 `AIQuotaMonitor.exe`，保留同目录的 `config.json` / Replace the executable and keep `config.json`.
3. 启动 1.8.0 并刷新卡片。已有账号、独立会话与历史无需迁移 / Start 1.8.0 and refresh; existing accounts, isolated sessions and history need no migration.
4. 标准 Usage 地址无需增加规则；若页面较慢且暂时缺少 Credits，提高服务的「额外等待秒数」后刷新 / Standard Usage URLs need no additional rules. If Credits is temporarily missing on a slow page, increase the service's Extra wait seconds and refresh again.
